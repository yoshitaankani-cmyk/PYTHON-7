# Student Marks Matrix Analysis

## About the Project
The Student Marks Matrix Analysis system is designed to store and analyse the marks of multiple students across different subjects using nested lists.

## Objectives
- Store student marks in a matrix.
- Calculate student-wise total marks.
- Calculate student-wise average marks.
- Calculate subject-wise average marks.
- Generate a marks report.

## Concepts Used
- Variables and data types
- Nested lists
- For loops
- Arithmetic operators
- Matrix operations

## How the Program Works
1. The user enters the number of students and subjects.
2. Marks are collected for every student.
3. The marks are stored in a nested list.
4. The program calculates each student's total and average.
5. Subject-wise averages are calculated.
6. The complete marks report is displayed.

## Conclusion
This project demonstrates how nested lists and loops can be used to store, process, and analyse student examination records.
